# New Registration — 4-step flow

## Step 1: Patient characteristics

**Route:** `/rag/add/characteristics`

### Search CURP
The CURP input is a custom combobox that doesn't respond to
`browser_type`. Use `browser_run_code`:

```js
async (page) => {
  const input = page.getByPlaceholder('Escribe para buscar por CURP...');
  await input.clear();
  await input.type('NEUC900101HDFRAI09', { delay: 50 });
  await page.waitForTimeout(1000);
}
```

If the CURP doesn't exist, a dialog appears: "¿Es este un nuevo
paciente?" with a "Continuar" button. Click it to proceed to create.

### Clinical data form

**Route after Continuar:** `/rag/add/characteristics/create?curp=...`

Required fields (use `browser_fill_form`):

| Field | Type | Example values |
|---|---|---|
| Fecha de nacimiento | textbox | 1990-01-01 |
| Sexo al nacer | combobox | Hombre, Mujer, Intersex, Indeterminado |
| CURP | textbox (prefilled) | — |
| Identificacion de genero | combobox | Hombre cisgenero, Mujer cisgenero, etc. |
| Peso (kg) | spinbutton | 75 |
| Talla (cm) | spinbutton | 175 |
| Condiciones | checkboxes | Diabetes, Inmunocompromiso, Cardiovascular, Renal, Hepatica, Embarazo |
| Alergias | checkboxes | Penicilinas, Quinolonas, Macrolidos, Cefalosporinas, Tetraciclinas, Sulfonamidas, Aminoglucosidos |
| Hospitalizado 3 meses | combobox | Si, No |
| Antibioticos 3 meses | combobox | Si, No |
| Discapacidad | combobox | Si, No |
| Viaje fuera del pais | combobox | Si, No |
| Indigena | combobox | Si, No |
| Afrodescendiente | combobox | Si, No |

There are 3 optional collapsible sections: "Otros datos",
"Contacto", "Ocupación".

Click "Guardar" then "Siguiente".

## Step 2: Primary condition

**Route:** `/rag/add/primary`

4 large buttons:
- **IVU** — Urinary tract infection
- **ITS** — Sexually transmitted infections
- **IRAS** — Upper respiratory tract infections
- **EDAS** — Acute diarrheal diseases

Clicking one redirects to step 3.

## Step 3: Secondary symptoms

**Route:** `/rag/add/define/iras` (or `its`, `ivu`, `edas`)

Contains multiple symptom groups with `react-select` dropdowns.

To interact with the dropdowns:
```js
async (page) => {
  // Open dropdown N (they start at 2)
  await page.locator('#react-select-2-input').click();
  await page.waitForTimeout(300);
  // Select option by partial text
  await page.getByText('Fiebre', { exact: false }).click();
}
```

Multiple options can be selected by repeating the pattern.

Click "Siguiente" when done.

## Step 4: Review and diagnosis

**Route:** `/rag/add/revise?vID=...&cID=...`

Shows:
- Patient summary (data, condition, symptoms, allergies)
- Diagnosis generated by the clinical algorithm
- Treatment recommendations (antibiotic or not)

This is the final screen of the flow — read-only.
